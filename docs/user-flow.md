# 사용자 흐름

## 1. 사용자

금융기관 데이터 분석 담당자

---

## 2. 기본 사용 흐름

### STEP 1. 대시보드 접속

사용자는 대시보드에 접속한다.

### STEP 2. 전체 대출 현황 확인

전체 대출 건수와 대출 잔액을 확인한다.

### STEP 3. 상품별 위험도 확인

대출 상품별 연체율을 비교한다.

### STEP 4. 신용등급별 위험도 확인

신용등급별 부실률을 확인한다.

### STEP 5. 기간별 위험 추이 확인

기간에 따른 연체율 변화를 확인한다.

### STEP 6. 지역별 위험도 확인

지역별 대출 위험도를 비교한다.

### STEP 7. 이상치 확인

분석 과정에서 발견된 이상치 데이터를 확인한다.

---

## 3. 사용자 흐름 요약

대시보드 접속
    ↓
전체 대출 현황 확인
    ↓
상품별 위험도 확인
    ↓
신용등급별 위험도 확인
    ↓
기간별 위험 추이 확인
    ↓
지역별 위험도 확인
    ↓
이상치 데이터 확인
