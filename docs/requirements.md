# 요구사항 정의서

## 1. 프로젝트 개요

### 프로젝트명
Loan Risk Dashboard

### 목적
금융기관의 대출 데이터를 분석하여 상품별, 신용등급별, 지역별 위험도를 파악한다.

### 사용자
금융기관 데이터 분석 담당자

---

## 2. 핵심 문제

대출 데이터가 여러 기준으로 분산되어 있을 경우 전체적인 대출 위험도를 한눈에 파악하기 어렵다.

따라서 대출 데이터를 통합하고 주요 위험지표를 분석하여 대시보드로 제공한다.

---

## 3. 기능 요구사항

### FR-001 전체 대출 현황 조회

사용자는 전체 대출 건수와 대출 잔액을 확인할 수 있어야 한다.

### FR-002 상품별 연체율 조회

사용자는 대출 상품별 연체율을 확인할 수 있어야 한다.

### FR-003 신용등급별 부실률 조회

사용자는 신용등급별 부실률을 확인할 수 있어야 한다.

### FR-004 기간별 위험 추이 조회

사용자는 특정 기간의 연체율 변화를 확인할 수 있어야 한다.

### FR-005 지역별 위험도 조회

사용자는 지역별 대출 위험도를 비교할 수 있어야 한다.

### FR-006 이상치 데이터 조회

사용자는 분석 과정에서 발견된 이상치 데이터를 확인할 수 있어야 한다.

### FR-007 대시보드 제공

사용자는 주요 분석 결과를 하나의 화면에서 확인할 수 있어야 한다.
