# Loan Risk Dashboard

금융기관 대출 데이터를 분석하여 상품, 신용등급, 지역별 위험도를 확인하는 금융 데이터 분석 프로젝트입니다.

## 프로젝트 목적

대출 데이터를 기반으로 연체율과 부실률을 분석하고,
주요 위험 요인을 대시보드 형태로 시각화합니다.

## 주요 기능

- 전체 대출 현황 조회
- 상품별 연체율 분석
- 신용등급별 부실률 분석
- 지역별 위험도 분석
- 기간별 위험지표 추이 분석
- 이상치 데이터 탐색
- 분석 결과 대시보드 제공

## 기술 스택
- Python
- Pandas
- MySQL
- Streamlit
- Git / GtiHub
